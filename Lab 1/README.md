# Lab 1: Introduction to C++ and Classes

This lab contains basic C++ console output and an introduction to classes and objects.

## Programs

### `Hello.cpp`

Prints a `Hello World!` message along with the student's name and lab question number.

Concepts demonstrated:

- The `main()` function
- Including and using `<iostream>`
- Console output with `cout`

### `Class_Obj.cpp`

Defines a `Pen` class with private `price` and `brand` data members. The program creates a `Pen` object, assigns it the brand `Natraj` and price `12`, and displays the stored information.

Concepts demonstrated:

- Defining a class
- Private data members
- Public member functions
- Creating and using an object
- Basic encapsulation
