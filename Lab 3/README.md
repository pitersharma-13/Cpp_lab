# Lab 3: Conditional Statements and Arithmetic

This lab contains small C++ programs that use input, arithmetic, comparisons, and conditional statements.

## Programs

### `EvenOdd.cpp`

Reads an integer and reports whether it is even or odd using the modulus operator (`%`) and an `if/else` statement.

### `LorS.cpp`

Reads two integers and displays the larger value. If both values are equal, it displays an equality message.

### `VorC.cpp`

Reads one character and checks it against lowercase and uppercase vowel characters. It reports whether the character is a vowel or consonant.

The program treats any character that is not one of `a`, `e`, `i`, `o`, `u` (in either case) as a consonant.

### `cal.cpp`

Defines a `cal` class that reads two integers and displays their sum, difference, product, and quotient.

Division is integer division because the operands are integers. The second number must not be zero.

### `display.cpp`

Reads three integers and displays the middle value using comparisons. Equal values are handled by the comparison conditions.

### `io.cpp`

Reads a person's age and reports voting eligibility in Nepal. The program uses `18` as the minimum eligible age.
